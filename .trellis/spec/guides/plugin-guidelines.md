# Canvas Node Plugins

Read `plugins/canvas/README.md` and `plugins/canvas/sdk/README.md` before changing plugin behavior.

Each plugin owns `plugins/canvas/<name>/` with its own `package.json`, `build.mjs`, `src/index.tsx`, and README. Start from `plugins/canvas/template/` when creating a plugin; do not turn optional extension nodes into new built-ins without a requirement.

## SDK Contract

`plugins/canvas/sdk/src/define-plugin.ts` supplies `definePlugin`. `plugins/canvas/sdk/src/types.ts` supplies node/context contracts. SDK hooks and automatic JSX use the host React singleton; do not bundle another React runtime.

`plugins/canvas/template/src/index.tsx` demonstrates `ctx.updateMetadata`, `ctx.getUpstream`, and `ctx.applyOps`. Use these APIs rather than reaching into internal stores. Keep plugin and node IDs unique, following `pluginId:name` node names.

Interactive controls preserve the canvas no-zoom/drag boundary and use `ctx.theme` colors. Follow current flat-action rules from `AGENTS.md`, even when older template styling is heavier.

## Host and Distribution

Host loading/registration lives in `web/src/lib/canvas/plugin-loader.ts`, `web/src/lib/canvas/plugin-runtime.ts`, and `web/src/lib/canvas/node-registry.ts`. Registry publishing lives in `plugins/canvas/registry/`. Plugin dist directories and host public plugin assets are generated by user-run builds and ignored via `.gitignore`; those output directories need not exist in this checkout.

Do not automatically build plugins. When user verification is requested, check enable/disable, metadata edits, references, theme switching, and canvas interaction without disturbing existing browser tabs.

Plugin discovery/loading begins only after authenticated business hydration. Capture the original session signal for manifest/source fetches, check it before dynamic import and after import before invoking factories/activation, and guard store updates. Reset deactivates development plugins too. Plugin lists/private JSON persist through application records; plugins remain trusted code running in the page, not sandboxed code or a way to hide AI keys from authenticated browsers.

## 验收矩阵（默认只记录，不执行）

| 对应标准 | 手工/回归场景 | 预期 |
| --- | --- | --- |
| AC1 | 延迟集合读取，交错连续记录写入及集合替换 | 版本不倒退，后续保存正常；集合屏障前后顺序正确 |
| AC1 | 无集合任务时并行保存不同键和不同命名空间 | 保留现有并行能力，无新增全局限制 |
| AC2、AC4 | 打开工作台同步 WebDAV，保留输入、参考和正在进行的生成 | 不重置会话/页面，历史就地更新，旧刷新不能覆盖新列表 |
| AC3 | 下载期间编辑/新建画布和素材、删除画布、完成生成 | 最新本页面状态保留；过期历史替换明确失败而非覆盖 |
| AC5 | 多领域引用相同缺失媒体键；已清理键也有远端备份 | 同次下载保存一次，清理键不复活 |
| AC6 | 两个独立页面实际修改同一记录 | 旧写入仍拒绝，提示来源中性；不自动丢弃修改或强制覆盖 |
| AC2、AC7 | 请求失败、退出或账号切换发生在读写/同步途中 | 失败可见，旧任务不更新新会话，不保存空业务状态 |

仅用户明确要求验证时，从 `web/` 使用已有 `bun test` 对应回归文件；类型检查和构建也必须另有授权。任何模拟验收必须使用独立测试页面/数据，不关闭用户现有页面。

## 审阅与回退重点

- 集合屏障必须在调用时登记，不能先 await 再入队；后续记录写入必须等待缓存更新完成。
- 队列失败清理和订阅通知不能跨会话，不得遗漏仍有效的新任务或把通知错误当成保存失败。
- 不把新的服务端修订号与旧待替换集合组合，真实冲突不得自动重试。
- 当前画布/素材状态的最终读取必须在异步媒体工作之后；上传使用实际应用的数据。
- 删除同步整页重新加载后，确认历史仍更新且视频恢复不会重复启动。
- 回退只处理本任务的修改；不得删除或迁移用户数据库、媒体、备份、未跟踪研究文件。

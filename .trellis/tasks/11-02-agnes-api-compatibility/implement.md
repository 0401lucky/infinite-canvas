## 命令策略

实施阶段遵守不自动检查/测试/构建的限制；用户随后明确要求使用 Docker Desktop 启动项目测试，本轮因此执行必要的本地镜像构建、该镜像中的 Agnes 专用 `bun test` 和独立 Chrome 验收。未授权的语法/type/lint 检查、格式化、Git 提交或远程部署仍不执行，不以“质量门”覆盖 AGENTS.md。真实 API 请求仍只允许官方当时明确免费的模型，且必须先取得可用的内存凭据。

不使用关闭 TLS 验证的客户端携带 Key；不把凭据放入日志、脚本、配置文件、任务附件、命令行参数或 Git。

## 高风险点与停止条件

- 无关或用户未授权的工作区变化：立即停止并询问，不覆盖或回滚。
- 若必须改变全局超时、重试、并发、大小限制或私有媒体公开性：回到规划，说明默认值与失败处理并取得确认。
- 如服务实测揭示新增的产品范围或参数语义问题：更新设计并重新提交最终审阅，不自行扩展兼容分支。
- 代码回退只撤销本任务新增的服务分支与文案/文档项；不触碰数据库、旧用户配置或其他渠道。

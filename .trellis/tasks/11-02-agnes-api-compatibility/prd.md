# Agnes 内置渠道与文本、图片、视频 API 适配

## Goal

让用户通过内置 Agnes 渠道填写 Key 后使用文本、图片和文生视频能力，修复已部署画布的参数/协议差异，并与其他渠道明确隔离。

## Background

- 用户提供 Agnes API 地址 `https://apihub.agnes-ai.com`，确认测试 Key 有效。
- 用户截图中生图模型显示 `output_format` 不是支持的字段；文本、视频也被报告无法使用。
- 用户允许实际生成，范围仅限 Agnes 官方明确标记免费的文本、图片、视频模型。
- 用户已批准最新的「原兼容方案 + 内置 Agnes 渠道」最终规划，要求优先适配视频、不等待免费队列恢复。上一会话仅保存批准状态和交接，本会话按已批准方案实施。

## Requirements

- R1：读取 Agnes 官方接口资料与免费模型清单，分别核对模型 ID、请求路径、必填/不支持字段、响应格式、流式或异步流程。
- R2：沿现有配置、模型发现和文本/图片/视频请求链路定位兼容差异，区分已证实的问题与待实测假设。
- R3：具备安全可用凭据时，对官方免费模型做最小量请求验证；不调用收费模型，不输出凭据，不将凭据写入文件、任务文档或仓库。
- R4：评估浏览器直连所需的 CORS 和生成媒体获取约束，不把服务端 HTTP 成功等同于线上画布成功。
- R5：提出复用现有结构、按显式渠道类型隔离的最小适配方案，明确既有渠道回归范围；新增范围待用户批准最新规划后才修改业务代码。
- R6：未经用户额外批准，不调整应用超时、重试、并发、大小限制，不执行构建、类型/语法检查、自动化测试、提交或部署。
- R7：第一轮实施提案覆盖默认官方渠道的文本（含识图）、文生图/图生图、文生视频任务创建/查询/恢复；保留多图结果数量、流式反馈、原始比例、私有持久化与已有脚本优先级，不影响其他渠道。
- R8：遇到上游队列满或未支持设置时明确反馈，不静默丢弃参考素材、不切换模型、不添加自动重试；第一轮不公开私有视频参考素材，也不宣称视频生成闭环已经验证。
- R9：增加内置 Agnes 新增入口，预填固定官方地址和当前免费的 Flash 模型，只需用户填 Key；复用现有模型选择与调用脚本。旧手填渠道可明确切换到 Agnes，保留 Key/模型/脚本，不自动迁移、覆盖默认模型或补回删除项。
- R10：优先完成视频协议和任务恢复，即使免费队列持续拥堵也不阻塞其余适配；任务身份显式区分 Agnes，不能恢复到通用 OpenAI 查询路径。

## Acceptance Criteria

- [x] AC1（R1）：每种能力都有官方来源和请求/响应契约摘要，免费与收费模型不混用。
- [x] AC2（R2）：截图错误有具体代码位置与官方协议证据；文本和视频分别给出已验证结论或明确验证缺口。
- [x] AC3（R3）：调用记录只保存脱敏请求结构、状态与必要响应摘要；无法调用时明确原因，不宣称已成功。
- [x] AC4（R4）：明确浏览器直连、流式响应和媒体读取的实际结果或剩余验收事项。
- [x] AC5（R5）：形成可审阅的 `design.md`、`implement.md`，列明变更边界、验证步骤和其他渠道回归要求。
- [x] AC6（R6）：调研阶段不改业务实现、不执行未经允许的检查、不写入或披露 Key。
- [ ] AC7（R7）：用户批准后，按 `implement.md` V1–V4 验收官方渠道的文本/识图与生图/图生图，数量、比例和引用不变。
- [ ] AC8（R7、R8）：按 V5–V6 验收视频协议、错误提示与恢复；队列不可用时只记录未验证，不宣布视频成功。
- [ ] AC9（R7、R8）：按 V7–V8 验收私有持久化、取消/旧会话、其他渠道与代理隔离；将实际改动记录到待测试与 CHANGELOG。
- [ ] AC10（R9）：从「新增渠道 → Agnes」创建预设，填写 Key 后可选择预填模型生成；刷新与配置导入/导出保留 Agnes 类型，不覆盖已有渠道、默认模型或节点。
- [ ] AC11（R9、R10）：旧手填渠道只有明确切换到 Agnes 才走专用协议；任务创建、持久化和恢复保留 Agnes 身份；普通 OpenAI/Gemini 不被 hostname 或模型名触发改写。

## Review Decisions

已确认的映射保持：自动图片分辨率按 1K；Flash 视频按 720P，默认 6 秒不变，只接受官方 4–12 秒而不静默截断；识图 Chat 的 xhigh 映射到 max；不支持的选项明确反馈，不改变全局限制。

已确认的内置渠道设计：「新增渠道 → Agnes」提供独立内置类型和预设模型，视频先实施；旧手填渠道显式转换，不做运行时域名猜测或自动迁移。新增渠道不自动覆盖用户的默认模型，用户在既有模型选择器选择对应 Agnes 模型。

实施后用户追加 Docker Desktop 本地启动与测试授权，允许必要的本地镜像构建和定向验收；不改变参数方案，也不授权语法/type/lint 检查、格式化、提交或远程部署。当前受保护凭据引用无法解析，真实 Agnes 验收仍待可用的内存凭据；已完成的本地模拟/私有存储案例见 `research/docker-validation.md`，AC7–AC11 不以模拟结果代替完整验收。

暂不实现私有视频参考素材。该项需要证明 Data URI 推理支持或另行讨论公开 URL 的安全方案，不能从队列入口错误推断已支持。

## Out of Scope

- 收费模型验证、完整模型穷举、压测和大批量生成。
- 修改线上配置或数据、发布版本、自动部署与 Git 提交。
- 无关 UI 重构、数据库/配置存储结构迁移、新增服务端 AI 代理。
- 将画布私有媒体公开、复杂工具调用、完整音视频参考与通用提供方适配框架。

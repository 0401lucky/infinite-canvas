# 管理员登录与服务端持久化

## 目标

为个人使用提供单管理员登录，把配置和业务数据从浏览器持久化改为服务端 SQLite 与媒体文件目录，通过手动清空图片释放空间，便于持续循环使用。

## 需求

### R1 单管理员认证

- 提供登录、会话恢复和退出登录；管理员密码保存哈希，数据库不保存明文密码。
- 服务端验证会话，业务数据、图片原文件和缩略图接口均要求认证，不能仅依赖前端路由限制。
- 登录前不读取私有配置，也不启动依赖私有数据的提示词刷新、插件或 Agent 页面副作用。
- 不恢复注册、用户管理、多角色和积分系统。
- 不添加 IP 登录限流，也不替换为账号锁定、验证码或其他未经确认的登录次数限制。

### R2 服务端业务持久化

- SQLite 保存配置、API Key、管理员认证数据、画布项目、素材、生成记录、提示词源及其缓存和插件持久化数据。
- 新业务数据不得继续持久化到 IndexedDB/localStorage，服务端失败时不得静默回退浏览器存储。
- 浏览器仅保留运行时内存和极小的本机偏好，如主题、语言、面板尺寸及本地 Agent 连接设置。
- 保留现有页面、Zustand 动作和消费者，优先替换真正的存储入口，不逐页面重写业务逻辑。
- 数据读取失败须与空数据区分；保存失败须明确提示，不得用空内存覆盖服务端数据或显示保存成功。
- API 请求继续由浏览器直连现有 AI 服务或现有本地代理。登录后的浏览器仍会读取 API Key；服务端持久化不等于对已登录浏览器隐藏密钥。

### R3 媒体与现有功能

- 图片原文件、缩略图、视频、音频及现有引用媒体保存在服务端文件目录，数据库保存路径、大小和关联信息。
- 刷新后仍能预览、按原文件下载、导出和作为生成参考；保持图片原始比例，不用缩略图替代原始资源。
- 下载或存储失败明确反馈，不伪造资源已保存；可显示的远端 URL 不等于服务端已保存的原文件。
- 保留现有 ZIP 导入/导出、WebDAV 和媒体功能，不顺手删除或重构本地 Agent 协议与消息历史。

### R4 图片统计与手动清理

- 设置页面展示真实服务端图片数量、原文件与缩略图占用，并提供手动清理入口。
- 确认后清空全部已保存图片原文件和缩略图，包括被画布、素材和生成历史引用的图片；旧图片显示“已清理”。
- 保留账号、API 渠道、API Key、生成偏好、项目结构、文字、视频、音频和本地 Agent 消息历史。
- 同步处理文件、元数据、相关图片引用和前端缓存；不保留可继续显示旧图的失效路径或备用 URL。
- 已清理图片不能作为有效下载、预览或生成参考，也不能通过现有 WebDAV 同步自动恢复；不删除 WebDAV 上已有备份。
- 用户主动重新上传或导入备份中的原文件属于新媒体，不等于自动迁移或自动恢复旧图片。
- 清理失败明确报告未完成，不把部分清理当作全部成功。

### R5 部署与已确认边界

- 使用 Docker 挂载持久化数据目录，覆盖 SQLite 数据库、关联文件与媒体；重启或更新容器不应丢失数据。
- 不另行部署 MySQL、Redis 或对象存储服务，不内置弱默认密码；明确管理员设置、启动、更新与持久化说明。
- 不自动迁移旧浏览器业务数据，不新增旧字段兼容分支；本地 Agent 消息存储的独立版本、备份和拒绝覆盖规则继续保留。
- 不自行增加其他请求超时、自动重试、并发上限或资源阈值；若确需调整，先说明默认值与失败处理并取得确认。

| 环节 | 用户已确认的默认值 | 达到边界后的处理 |
| --- | --- | --- |
| 登录会话 | 登录后保留 7 天 | 到期重新登录，退出立即撤销；部署配置可调整 |
| 图片、视频、音频单文件上传 | 512 MiB | 返回 413，提示失败，不保存残缺文件，不回退浏览器存储 |
| 配置、画布等单次 JSON 写入 | 32 MiB | 返回 413，提示保存失败，不截断或覆盖原数据 |

## 验收标准

- [ ] A1（R1）：未登录或密码错误时不能读取私有配置、业务数据、原文件或缩略图；正确登录后可恢复会话，退出和到期后不能继续访问。
- [ ] A2（R1、R2）：登录前不请求私有存储、不启动私有数据副作用；读取失败有明确反馈，空初始状态不覆盖服务端数据。
- [ ] A3（R2）：修改配置、画布、素材和历史并保存后，刷新或在另一浏览器登录可读取；服务端失败不显示成功或回退本地业务存储。
- [ ] A4（R3）：图片、视频、音频和引用媒体可刷新后使用；原文件下载、预览、参考和导出正确，画布比例不变。
- [ ] A5（R4）：清理统计与实际文件占用一致；确认后释放全部已保存图片及缩略图空间，旧图片在画布、素材和历史中显示“已清理”。
- [ ] A6（R4）：清理不删除账号、配置、文字、项目结构、视频、音频或本地 Agent 消息历史；部分失败不能报告全部成功。
- [ ] A7（R3、R4）：WebDAV 不自动恢复已清理图片；ZIP 导出保留已清理状态，主动重新导入含原文件的备份可作为新媒体使用。
- [ ] A8（R5）：7 天会话、512 MiB 文件和 32 MiB JSON 默认值按确认执行，超出时不残留损坏数据；不添加 IP 或替代登录次数限制。
- [ ] A9（R5）：容器重启、更新后账号、会话、业务数据和媒体仍可读取；只替换应用镜像，不清空挂载目录。
- [ ] A10（R5）：更新 AGENTS、Trellis specs、启动部署说明、TODO、待测试文档及 Unreleased 归纳，不把未验收功能写成正式已确认能力。

## 范围外

- 多用户、公开注册、角色权限、积分计费和旧后台整套恢复。
- 实时协作、对象存储、自动定时清理、备份平台和旧浏览器数据自动迁移。
- 本地 Canvas Agent 通信协议、CLI 适配器和消息历史格式重构。
- AI 提供商请求协议改写、服务端 AI 网关、无关 UI 重设计和静态托管平台改造。
- 自动语法检查、类型检查、测试、构建、委派、Git 提交、合并或发布。

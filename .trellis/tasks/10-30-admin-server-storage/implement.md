## 风险与回退点

- 认证门控和异步 store 写入风险最高：先完成服务接口，再接前端；若失败留在加载/错误状态，不增加本地兜底。
- 图片清理无法事务回滚：使用阶段与 tombstone，不能通过恢复旧 JSON 伪装恢复文件；操作前必须明确确认。
- 共享数据库不等于实时协作：修订冲突需要重新加载，其他已打开客户端的清理状态需刷新，不加入自动跨端合并。
- 新服务依赖原生 SQLite/Argon2，实际安装、容器权限与运行留待用户验证；不把依赖元数据调查当作执行测试。
- 若回退业务改动，只处理本任务新增/修改范围，保留初始 AGENTS、CHANGELOG、文档和 Trellis 初始化改动；绝不 reset/checkout 整个工作区或删除持久化数据目录。

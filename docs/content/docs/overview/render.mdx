# Deploy on Render

[Deploy to Render](https://render.com/deploy?repo=https://github.com/basketikun/infinite-canvas)

The existing one-click configuration has not been adapted to the new administrator service and SQLite/media persistence. It does not configure the required administrator credentials or persistent disk; do not use the old flow expecting durable personal data.

A Render deployment would need an application Web Service, a persistent data directory, `ADMIN_PASSWORD`, and `APP_ORIGIN` matching the assigned HTTPS domain. Free ephemeral storage is not a substitute for the application data volume. This platform adaptation is outside the current implementation and has not been verified.

For the current source, follow [Docker deployment](/docs/overview/docker). Vercel's old static-only configuration also cannot provide the new authentication and storage service. WebDAV remains optional backup/sync, not a replacement for SQLite persistence.

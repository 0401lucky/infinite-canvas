# Docker 部署

主应用镜像现在使用 Node.js 24 应用服务，同时提供认证 API 和 Vite 静态前端。这些 Unreleased 部署改动仍需人工验证；验收时应从当前源码本地构建，不要假设 `latest` 已包含改动。

## 先配置管理员

复制 `.env.example` 为 `.env`，设置强密码 `ADMIN_PASSWORD`。远程部署还须将 `APP_ORIGIN` 改为浏览器实际访问的 HTTPS 源。密码、API Key 和数据目录不能放入公开的 `config.js` 或静态资源目录。

## 使用发布镜像

```bash
git clone git@github.com:basketikun/infinite-canvas.git
cd infinite-canvas
cp .env.example .env
# 启动前填写 ADMIN_PASSWORD 和 APP_ORIGIN
docker compose up -d
```

启动后访问：

```text
http://localhost:3000
```

## 本地构建镜像

如果需要基于当前源码构建镜像：

```bash
docker compose -f docker-compose.local.yml up -d --build
```

## 文档站镜像

文档站位于 `docs/` 目录，按带服务端能力的 Next.js standalone 应用单独构建，不打进主应用镜像。

使用发布镜像：

```bash
cd docs
docker compose up -d
```

基于当前源码本地构建：

```bash
cd docs
docker compose -f docker-compose.local.yml up -d --build
```

## 数据说明

Compose 将当前项目的 `app-data` 持久化卷挂载到 `/app/data`，包含 `app.sqlite`、WAL/SHM 关联文件、图片原文件、缩略图、其他媒体和上传临时文件。更新或重建容器时保留这个卷，不要执行 `docker compose down -v` 或把删除卷当成更新步骤。直接备份文件系统前先停止应用，再备份完整卷。

两个 Compose 文件在相同 Compose 项目下使用同一个卷；改变项目名会选择不同的卷。改用宿主目录挂载时，目录需要允许运行用户 `node`（UID 1000）写入，不能位于公开静态资源目录中。

本版需要 Node.js、SQLite 和私有媒体存储，不能仅部署静态前端。AI 提供商、提示词来源和 WebDAV 仍由浏览器请求。本地 Canvas Agent 的存储独立，不受图片清理影响；旧浏览器数据不会自动迁移。

| 配置 | 默认值与行为 |
| --- | --- |
| `ADMIN_USERNAME`、`ADMIN_PASSWORD` | 用户名默认 `admin`，首次启动必须设置密码；明确修改用户名或密码会撤销已有会话。 |
| `APP_ORIGIN` | 默认 `http://localhost:3000`，必须与实际访问源一致；HTTPS 部署启用 Secure Cookie。 |
| `SESSION_TTL_DAYS` | 从登录起固定 7 天，不自动续期。 |
| `MAX_UPLOAD_MIB` | 单文件 512 MiB；超限返回 413，不保留未完成文件。 |
| `MAX_JSON_MIB` | 单次 JSON 32 MiB；超限不截断或覆盖原记录。 |

没有 IP 登录限流、账号锁定或注册功能，公网使用强密码和 HTTPS。登录后的浏览器仍能读取 AI API Key；数据库、环境文件和备份都应按敏感数据保护。容器重启/更新、目录权限、SPA 路由、插件静态资源与媒体 Range 响应仍是待验收项，不宣称生产部署已经验证。

## 统计分析（可选）

项目**默认不接入任何统计**：不设置下列环境变量时，页面不会加载任何统计脚本，也不会发送任何外部请求。你在自己的部署上想查看流量时，设置对应环境变量即可，无需修改代码或重新构建镜像——镜像启动时会据此生成运行期配置。

统计按「每家一个独立变量」配置：**填了谁就启用谁，可同时启用多家**（例如 GA4 + 百度一起开）。仅支持 GA4 与百度，两者都只接受 ID，脚本地址由代码固定拼接，不接受任意脚本地址或内联 JS。

| 变量 | 说明 |
| --- | --- |
| `ANALYTICS_GA4_ID` | Google Analytics 4 衡量 ID（`G-XXXX`） |
| `ANALYTICS_BAIDU_ID` | 百度统计站点 ID（`hm.js?` 后面那串 hash） |

在 `.env` 中填写公开的统计 ID，重建容器后生效，例如：

```dotenv
ANALYTICS_GA4_ID=G-XXXXXXXXXX
ANALYTICS_BAIDU_ID=your-site-id
```

单页应用的路由切换会自动向所有已启用的统计上报 pageview。

<Callout type="warn">
请只在你自己的站点上配置统计 ID，不要把 ID 提交进仓库；fork 或自托管本项目的用户默认不会产生任何统计。
</Callout>

# Render 部署

点击下面链接即可部署到 Render：

[部署到 Render](https://render.com/deploy?repo=https://github.com/basketikun/infinite-canvas)

现有一键部署配置尚未适配新增管理员服务与 SQLite/媒体持久化，未设置所需管理员凭据和持久化磁盘，不能按旧流程期待长期保存个人数据。

Render 部署需要应用 Web Service、持久化数据目录、`ADMIN_PASSWORD`，以及与分配的 HTTPS 域名一致的 `APP_ORIGIN`。免费实例的临时文件系统不能替代应用数据卷。这部分平台适配不在当前实施范围，也未验证。

当前源码请参考 [Docker 部署](/zh-CN/docs/overview/docker)。旧 Vercel 纯静态配置同样不能提供本版的认证与存储服务；WebDAV 是可选备份/同步，不是 SQLite 持久化的替代品。

# 本地开发

React 应用位于 `web/`，`server/` 提供管理员认证、SQLite 记录和私有媒体文件。AI 请求仍由浏览器直连用户自己的提供商。新增流程仍需人工验收。

## 1. 配置并启动 API

从仓库根目录复制 `.env.example` 为 `.env`，设置强密码 `ADMIN_PASSWORD`。使用 Node.js 24 或更新版本；`APP_ORIGIN` 默认 `http://localhost:3000`，必须与浏览器实际访问源一致。

```bash
cd server
npm ci
npm run dev
```

API 默认端口为 `3001`，读取根目录 `.env`。业务数据默认写入仓库的私有 `data/` 目录，不能放在 `web/` 内或公开为静态资源。

## 2. 在另一个终端启动前端

```bash
cd web
bun install
bun run dev
```

前端默认访问：

```text
http://localhost:3000
```

## 3. 登录并配置模型

先登录，再打开右上角配置弹窗填写提供商信息。Vite 将 `/api` 转发到根目录 `.env` 中的 API 端口；私有应用 API 不走 AI 代理。两个进程都需要保持运行；加载/保存失败会明确反馈，不回退 IndexedDB/localStorage，也不自动迁移旧浏览器数据。

## 4. 启动文档站

如果需要单独调整文档站，在 `docs` 目录执行：

```bash
bun run dev
```

## 常见场景

- 改画布、页面和交互：主要看 `web/`
- 改认证、SQLite、媒体和空间清理：看 `server/src/`
- 改浏览器存储适配和会话生命周期：看 `web/src/lib/server-storage.ts`、`web/src/stores/use-user-store.ts`
- 改提示词缓存：主要看 `web/src/services/api/prompts.ts`
- 改文档站内容：主要看 `docs/content/docs/`
